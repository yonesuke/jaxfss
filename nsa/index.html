Neural Scaling Analysis (NSA)

Finite-size scaling (FSS) analysis is a fundamental technique in statistical physics and computational condensed matter physics for investigating critical phenomena and phase transitions from finite-size numerical simulation data.

Neural Scaling Analysis (NSA) is a machine learning framework that formulates finite-size scaling analysis as an end-to-end regression problem using neural networks. This package jaxfss provides a fast, JIT-compiled, flexible implementation of NSA built on top of JAX, Flax, and Optax.

1. Finite-Size Scaling Hypothesis¶

Near a continuous phase transition at a critical point TcT_{\mathrm{c}}Tc​, correlation lengths diverge and physical observables obey universal scaling relations. In a finite-size system with linear dimension LLL at temperature TTT, an observable A(T,L)A(T, L)A(T,L) follows the finite-size scaling law:

A(T,L)=L−c2F[(T−Tc)Lc1]A(T, L) = L^{-c_2} F\left[ (T - T_{\mathrm{c}}) L^{c_1} \right]A(T,L)=L−c2​F[(T−Tc​)Lc1​]
(1)

where:

  • TcT_{\mathrm{c}}Tc​ is the critical point (e.g., critical temperature).

  • c1=1/νc_1 = 1/\nuc1​=1/ν is the scaling exponent related to the correlation length exponent ν\nuν.

  • c2c_2c2​ is the anomalous dimension or scaling exponent of observable AAA.

  • F[⋅]F[\cdot]F[⋅] is the universal scaling function, which is generally unknown a priori.

The goal of scaling analysis is to estimate the critical parameters (Tc,c1,c2)(T_{\mathrm{c}}, c_1, c_2)(Tc​,c1​,c2​) such that data points (X,Y)=((T−Tc)Lc1,A(T,L)Lc2)(X, Y) = \left( (T - T_{\mathrm{c}}) L^{c_1}, A(T, L) L^{c_2} \right)(X,Y)=((T−Tc​)Lc1​,A(T,L)Lc2​) from different system sizes LLL collapse onto a single master curve F[X]F[X]F[X].

2. Motivation: Why Neural Networks?¶

Traditionally, two main methods have been used to perform finite-size scaling analysis:

  1. Polynomial regression:

    • Approximates the scaling function F[X]F[X]F[X] with a low-order Taylor polynomial.

    • Limitations: Only valid in a narrow region around the critical point (X≈0X \approx 0X≈0). Prone to overfitting or underfitting if the polynomial degree is mischosen.

  2. Gaussian Process (GP) regression (e.g., Harada’s Bayesian Scaling Analysis):

    • Provides non-parametric, flexible curve fitting with error estimation.

    • Limitations: Computational complexity scales as O(N3)\mathcal{O}(N^3)O(N3) where NNN is the number of data points, making it prohibitively heavy for large-scale or dense Monte Carlo datasets.

Neural Scaling Analysis (NSA) overcomes both limitations:

  • High expressiveness: Universal approximation capability of neural networks models arbitrary smooth scaling functions across wide parameter windows.

  • Linear computational complexity: With modern automatic differentiation and mini-batch / full-batch gradient descent in JAX, the computational cost scales as O(N)\mathcal{O}(N)O(N).

  • GPU/TPU acceleration: NSA easily scales to massive data using hardware acceleration.

Data Pre-Processing (CriticalData)¶

Neural networks train best when inputs and targets are standardized to order O(1)\mathcal{O}(1)O(1). CriticalData automatically applies affine transformations:

  • Rescales system size L∈(0,1]L \in (0, 1]L∈(0,1].

  • Rescales temperature T∈[−1,1]T \in [-1, 1]T∈[−1,1].

  • Rescales observable AAA.

Parameter Constraints (Bijectors)¶

Physical exponents often have known constraints (e.g., c1>0c_1 > 0c1​>0, or Tc∈[Tmin⁡,Tmax⁡]T_{\mathrm{c}} \in [T_{\min}, T_{\max}]Tc​∈[Tmin​,Tmax​]). Using bijectors (such as softclip.SoftClip), unconstrained optimization variables ppp are mapped to physical parameters:

  • c1=SoftClip(p1;low=0.0)c_1 = \mathrm{SoftClip}(p_1; \mathrm{low}=0.0)c1​=SoftClip(p1​;low=0.0)

  • Tc=SoftClip(pc;low=Tmin⁡,high=Tmax⁡)T_{\mathrm{c}} = \mathrm{SoftClip}(p_c; \mathrm{low}=T_{\min}, \mathrm{high}=T_{\max})Tc​=SoftClip(pc​;low=Tmin​,high=Tmax​)

Activation Functions (RationalMLP)¶

Standard ReLU or sigmoid networks can have derivative discontinuities or saturation issues. RationalMLP uses trainable rational functions P(x)/Q(x)P(x)/Q(x)P(x)/Q(x) as activations, offering superior smoothness and expressiveness for physical functions.

5. Dual Optimization Strategy¶

Because the neural network weights θ\thetaθ and critical parameters ϕ\phiϕ have different optimization landscapes, it is advantageous to use separate learning rates:

  • lrmlp∼10−3\mathrm{lr}_{\mathrm{mlp}} \sim 10^{-3}lrmlp​∼10−3 for neural network parameters

  • lrfss∼10−2\mathrm{lr}_{\mathrm{fss}} \sim 10^{-2}lrfss​∼10−2 for critical exponents and critical point

jaxfss.fit supports passing a dictionary of Optax optimizers:

optimizer = {
    "mlp": optax.adam(learning_rate=1e-3),
    "fss": optax.adam(learning_rate=1e-2),
}
params, losses, critical_vals = jaxfss.fit(loss_fn, optimizer, init_params, steps=10000)
